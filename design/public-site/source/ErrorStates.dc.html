Error states

In production users never see server messages, codes, URLs or stack traces. They see short friendly copy from the app, and for server failures a short reference they can quote to support. Details go to the error tracker, and the full message is shown only in development.

Section failed to load
We could not load your proposals
Please try again.

Use when one part of a page fails. The rest of the page keeps working.

Action failed (toast)
!That did not go through. Please try again.

Use for a failed action with no form. The message never includes server text.

Form error
Use up to two decimal places.
Please fix the highlighted field and try again.

Field messages come from the app copy mapped from error codes.

Offline
●You are offline. We will reconnect when you are back.

Network failure is different from a server error.

Payment not confirmed yet
We are confirming your payment
This can take a minute. Do not pay again. We will update this page.

Used on the payment return page while the status is polled. It is not an error.
